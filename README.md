# وش السالفة؟ — موقع أخبار عربي

منصة أخبار وترندات عربية تركّز على عرض الأخبار المنشورة بعد مراجعتها، مع فصل الخبر عن الرأي وتوضيح المصادر والتصحيحات.

## صفحات الموقع
- `index.html`: الصفحة الرئيسية.
- `about.html`: من نحن.
- `contact.html`: اتصل بنا.
- `privacy.html`: سياسة الخصوصية.
- `editorial-policy.html`: المعايير التحريرية والتصحيح.
- `robots.txt` و`sitemap.xml`: ملفات إرشاد وفهرسة لمحركات البحث.

## لوحة الإدارة
- `admin.html`, `admin.css`, `admin.js`: واجهة لوحة الإدارة.
- واجهة الإدارة ما زالت في مرحلة التجهيز؛ عمليات إنشاء الأخبار وتعديلها ومراجعتها ونشرها ليست جاهزة للاستخدام الإنتاجي.
- لا تعتمد على إخفاء الأزرار كوسيلة حماية. يجب فرض الصلاحيات من خلال RLS أو وظائف خادمية موثوقة واختبارها قبل تفعيل أي عملية.

## قاعدة البيانات والأمان
- المشروع يستخدم Supabase للمصادقة وقاعدة البيانات.
- لا تضع مفتاح `service_role` في ملفات المتصفح أو المستودع.
- لا تطبق ملفات SQL الموجودة في هذا الفرع على قاعدة البيانات الحية دون مراجعة مستقلة ونسخة احتياطية واختبار في بيئة منفصلة.
- إعداد MFA/AAL2 والتحقق من العامل الإداري واختبارات الدخول ما زالت خطوات لازمة قبل فتح وظائف الإدارة الحساسة.
- لا تغيّر حالات الأخبار الـ45 المنشورة الموجودة حاليًا. يجب أن يبدأ كل محتوى جديد بحالة `pending` أو `draft` ولا يظهر للزوار إلا بعد موافقة المدير.

## استيراد الأخبار وRSS
- الاستيراد المجدول ليس جاهزًا أو مفعّلًا في هذه النسخة.
- لا تفترض وجود وظيفة `import-rss` منشورة أو أسرار تشغيل مضبوطة حتى يتم إنشاء الوظيفة ونشرها واختبارها فعليًا.
- عند بناء المستورد، يجب أن يحفظ العناصر الجديدة كـ`pending` فقط، مع اسم المصدر ورابطه وتاريخ الالتقاط، ومنع التكرار، وعدم نشر أي عنصر تلقائيًا.
- راجع شروط استخدام كل مصدر وحقوق النصوص والصور قبل إعادة استخدامها.

## SEO والمحتوى
- ملفات sitemap وrobots مضبوطة حاليًا على عنوان GitHub Pages المؤقت:
  `https://saadasta5676-spec.github.io/wesh-alsalfah/`
- عند الانتقال إلى دومين جديد، يجب تحديث روابط sitemap وrobots والروابط canonical وبيانات المشاركة وإعدادات Supabase URL Configuration.
- وجود sitemap لا يضمن الفهرسة أو القبول في أي شبكة إعلانية.

## بيئة العمل
- فرع التطوير الحالي: `draft/admin-role-security`.
- لا تدمج هذا الفرع إلى `main` ولا تنشر الموقع الحي قبل مراجعة المستخدم وموافقته الصريحة.
- مشروع Vercel المنفصل مخصص لمعاينة هذا الفرع، وليس بديلًا عن نشر الموقع الحي.
